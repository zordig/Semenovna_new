# ByBit Card — Пошаговая инструкция

**Автор:** Мистер Банкир  
**Дата:** 5 июля 2025

---

## 1. Регистрация на бирже

Перейдите на биржу **ByBit** и создайте аккаунт.

Заполните форму регистрации:

- Email
- Пароль
- Промокод

**Промокод:**

```
BANKIR5000
```

Этот код дает возможность получить бонус **от $10 до $5000**.

Если появится всплывающее уведомление — нажмите **«ДА»**.

---

## 2. Переход к оформлению карты

⚠️ **Важно:** с этого момента используйте **VPN**.

Рекомендуемая геолокация:

```
Kazakhstan
```

Далее:

1. Перейдите на страницу оформления карты ByBit.
2. Нажмите **«Получить карту»**.
3. Войдите в свой аккаунт ByBit.

---

## 3. Заполнение анкеты

### Страна проживания

Выберите:

```
Kazakhstan
```

---

### Верификация (Level 1)

Далее необходимо выбрать **страну гражданства** (не проживания).

Например:

```
Russia
```

После этого нужно пройти стандартную верификацию личности.

Это обычная процедура, похожая на оформление банковской карты по паспорту.

---

## 4. Указание адреса проживания

Нужно указать адрес в Казахстане.

### Как найти адрес

1. Откройте **Google Maps**
2. Найдите любой город Казахстана
3. Выберите любой жилой дом
4. Нажмите на него

Например город:

```
Shuchinsk
```

### Пример заполнения

```
Street: Internatsionalnaya
House: 106
Apartment: любое число от 1 до 100
City: Shuchinsk
Postal code: 020000
```

📌 Важно:

- Адрес указывается **латиницей**
- Номер квартиры можно выбрать **любой**
- Эти данные обычно **не проверяются**

---

## 5. Дополнительная информация

Дополнительные поля можно заполнить **произвольно**.

Они практически ни на что не влияют.

---

## 6. Номер телефона

Для регистрации потребуется **номер телефона Казахстана**.

Автор инструкции использовал сервис **Grizzly SMS**, однако сейчас:

⚠️ Он **не принимает оплату через RU‑сервисы**.

### Альтернативные сервисы

- OnlineSim
- 365sms
- SMSFAST
- Sms Activate

---

### Покупка номера

1. Выберите сервис **ByBit**
2. Выберите страну

```
Kazakhstan
```

3. Скопируйте выданный номер
4. Вставьте его в форму ByBit

---

## 7. Подтверждение

Введите:

- код из **email**
- **SMS‑код**

После подтверждения номера введите бонусный код:

```
A0GN1RA
```

🎁 Бонус: **$10**

Условие получения:

Совершить покупки на **$100 в течение первых 30 дней**.

---

## Готово

После подтверждения анкеты карта будет оформлена.

Через **несколько минут или в течение дня** появится доступ к управлению картой в интерфейсе **ByBit**.
