Это инструкция по развёртыванию довольно популярной в 2024–2026 годах схемы обхода блокировок (цензуры, DPI) с использованием VLESS + TLS + fallback через панель управления 3X-UI.
Коротко — это способ создать свой личный VPN / прокси-сервер, который:
маскируется под обычный HTTPS-трафик (порт 443);
использует современный протокол VLESS с flow xtls-rprx-vision (очень быстрая и устойчивая к обнаружению реализация);
прячет настоящую панель управления за сложным путём;
прячет ссылки на подписку (subscription) за другим путём;
использует Nginx как reverse-proxy, чтобы на одном домене и одном порту 443 работало и несколько сервисов.
Что именно делает этот скрипт / инструкция
Обновляет систему (Debian/Ubuntu)
Устанавливает 3X-UI — веб-панель для управления Xray-core
Репозиторий: https://github.com/mhsanaei/3x-ui
Самая популярная и активно развивающаяся форк панели X-UI
Получает SSL-сертификат через саму панель (обычно Let's Encrypt)
Использует Cloudflare для получения токена (скорее всего для API DNS-01 challenge или для проксирования, но в тексте просто указан)
Создаёт inbound с настройками:
VLESS
порт 443
транспорт TCP (RAW)
безопасность TLS
ALPN: http/1.1
flow: xtls-rprx-vision (самый производительный и устойчивый режим на 2025–2026 год)
fallback на порт 8080 (туда падает обычный HTTP-трафик, чтобы сервер выглядел как обычный сайт)
Устанавливает nginx
Настраивает nginx так, чтобы:
80 → редирект на https
по пути /Ess5Ac26/ проксировалась подписка (subscription link)

всё это на портах, которые слушает Xray внутри (38947 и 35327 — случайные высокие порты)
